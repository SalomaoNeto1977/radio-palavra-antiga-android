# Rádio Palavra Antiga Android

Aplicação Android oficial da Rádio Cristã Portuguesa Palavra Antiga.

Este repositório é a fonte oficial do projeto Flutter/Android. A versão em preparação é a 1.0.8, com navegação inferior permanente Rádio | Música | WhatsApp, playlists oficiais atualizadas automaticamente e pedidos de músicas elegíveis diretamente na área Music.

O catálogo público em `catalog/official_playlists.json` é regenerado de hora a hora a partir das opções escolhidas no AzuraCast. Contém apenas nomes de playlists e identificadores públicos; a chave da API permanece protegida nos segredos do GitHub Actions.
